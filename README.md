# 🎓 LearnIx — All-in-One School Management System

<img src='public/assets/LearnIx.png' width='150px' alt='LearnIx logo' />




**LearnIx** is a full-stack, modern **School Management System (SMS)** built to digitalize and simplify academic and administrative workflows.  
With **React (Vite)** powering the frontend, **Node.js** managing backend logic, and **MongoDB** providing flexible data storage, LearnIx offers a powerful, responsive, and scalable platform for schools of all sizes.

---

## 🚀 Technology Stack

| Layer | Technology | Description |
|-------|-------------|-------------|
| **Frontend** | React + Vite | Fast, component-based UI with Hot Module Reloading |
| **Backend** | Node.js + Express | RESTful API and server-side operations |
| **Database** | MongoDB | NoSQL database for flexible, schema-less data storage |

---

## ✨ Core Features

### 🧭 Admin Dashboard
- Real-time metrics for students, teachers, and classes  
- Data visualizations for admissions, performance, and activity  
- Quick access to management tools and status summaries  

### 👩‍🏫 User Management
- Full lifecycle management for Students, Teachers, and Staff  
- Track user status (Active, Inactive, Pending)  
- Detailed user profiles and permissions  

### 📝 Admissions & Registration
- Structured workflow for student applications and approvals  
- Admission status tracking with progress updates  
- Notifications for new applicants or updates  

### 📚 Academic Setup
- Manage subjects, academic terms, and grading systems  
- Create timetables, exams, and performance evaluations  
- Supports flexible grading rules  

### 🗂️ Resource Management
- Centralized document library for files, past papers, and school rules  
- Simple upload, view, and organize features  
- Easy access for authorized users  

### 🔒 Security
- Role-Based Access Control (RBAC) for Admins, Teachers, and Students  
- Configurable permissions and restricted access  
- Optional Two-Factor Authentication (2FA) for enhanced protection

## 🛠️ Getting Started

### ✅ Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or later)  
- npm (comes with Node.js)  
- [MongoDB](https://www.mongodb.com/)  

---

### 🔑 Environment Variables

Before running the app, create a `.env` file in the root of the project and add the following variable:

```dotenv
VITE_API_BASE_URL = 'https://backend-orpin-alpha-75.vercel.app'
```

| Variable | Description |
|----------|--------------|
| `VITE_API_BASE_URL` | Base URL of the backend API that the frontend communicates with |

> ⚠️ Since this project uses **Vite**, all environment variables exposed to the frontend must be prefixed with `VITE_`.

### ⚙️ Installation

1. **Clone the repository**
```bash
   git clone <repository-url>
   cd learnix
```
2. **Install dependencies**
```bash
   npm install
```
3. **Start the frontend development server**
   Open a new terminal and run:
```bash
   npm run dev
```
✅ By default, your frontend will be served at [http://localhost:5173](http://localhost:5173)
